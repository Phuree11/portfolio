# วิธีแก้เนื้อหาเว็บ Portfolio

แก้เนื้อหาทั้งหมดที่ไฟล์เดียว: **`content.js`** (เปิดด้วย Notepad / VS Code ได้ หรือกดดินสอแก้บน GitHub)
ไฟล์อื่น (`index.html`, `style.css`, `app.js`) ไม่ต้องแตะ

## โครงสร้างเว็บ (ธีมอวกาศ หน้าเดียว ไม่เลื่อน)
- **หน้าเปิด** (ลิงก์หลัก) โชว์ชื่อเต็ม `fullName` + ตำแหน่ง `role`
- เมนู About / Work / Contact สลับหน้า (ลิงก์ตรง: `#about`, `#work`, `#contact`, `#p-รหัสผลงาน`)
- พื้นหลังเป็นวงโคจร แต่ละหน้ามีชุดของตัวเอง ดาวโคจรตามวงจริง และเฟดเข้า/ออกตอนเปลี่ยนหน้า
  (ตำแหน่งวงโคจรแก้ได้ใน `app.js` ส่วน `ORBITS` — ปกติไม่ต้องแตะ)
- หน้า Contact: แก้ใน `contact.groups` แต่ละกลุ่มมีหัวข้อ (เช่น For Work / Personal) กลุ่มที่ไม่มีแถวจะไม่แสดง
- หน้าผลงานแต่ละชิ้น (ที่กดเข้าไป) ยังใช้เลย์เอาต์เดิม รอออกแบบใหม่
- บนคอมพิวเตอร์ทุกหน้าย่อให้พอดีจอ; บนมือถือเลื่อนได้ปกติ
- ปุ่มจะจางตอนไม่ได้วางเมาส์ สว่างและเรืองแสงเมื่อวางเมาส์ หรือเมื่อเป็นหน้าปัจจุบัน

## โครงสร้างหน้าผลงาน (ตามดีไซน์ Figma)
รูป/วิดีโอ → ชื่อ → สถานะ + ช่วงเวลา + บทบาท → คำอธิบาย → รายการ "ทำอะไรบ้าง" → ปุ่มลิงก์

| ช่องใน content.js | แสดงตรงไหน |
|---|---|
| `title` | ชื่อผลงาน |
| `status`, `period` | "Ongoing  2025–Now" (สีเหลือง ใต้ชื่อ) |
| `role` | บทบาท (สีเหลือง คอลัมน์ขวา) |
| `description` | คำอธิบายคอลัมน์ซ้าย (ย่อหน้าละ 1 ก้อน) |
| `did` | รายการหัวข้อ "ทำอะไรบ้าง" คอลัมน์ขวา |
| `gameLink` | ปุ่ม Link Game (ถ้า `url` ว่าง ปุ่มจะเป็นสีจาง กดไม่ได้) |
| `links` | ปุ่มลิงก์อื่นๆ เช่น Figma, GDD (ไม่ใส่ `url` = ไม่แสดงปุ่ม) |
| `cover`, `title`, `role` | รูปและข้อความบนการ์ดหน้า Work |
| `media` | รูป/วิดีโอบนหน้าผลงาน (ดูด้านล่าง) |

## เพิ่มผลงาน
1. หา `projects: [ ... ]` แล้ว copy บล็อกผลงาน 1 ชิ้น (ตั้งแต่ `{` ถึง `},`) วางต่อท้าย
2. แก้ `id` (ภาษาอังกฤษ ไม่มีเว้นวรรค เช่น `my-game`) และข้อความไทย/อังกฤษ
3. ใส่รูปไว้ที่โฟลเดอร์ `images/` แล้วแก้ชื่อไฟล์ใน `cover` และ `media`

## ลบ / ซ่อนผลงาน
ลบบล็อกนั้นทิ้ง หรือเพิ่มบรรทัด `hidden: true,` เพื่อซ่อนชั่วคราว

## รูปและวิดีโอ (media)
- ใส่ได้หลายชิ้น (ในดีไซน์มี 6 ช่อง) ชิ้นแรกเป็นภาพใหญ่ ที่เหลือเป็นภาพเล็ก กดภาพเล็กแล้วจะสลับขึ้นมาเป็นภาพใหญ่
- รูป: `{ type: 'image', src: 'images/x.jpg', caption: { th: '...', en: '...' } }`
- YouTube: `{ type: 'youtube', id: 'รหัสท้ายลิงก์' }`
- ไฟล์วิดีโอ: `{ type: 'video', src: 'images/clip.mp4' }`
- ถ้าไม่ใส่ `media` จะใช้ `cover` เป็นภาพเดียว
- สัดส่วนรูปที่เหมาะ: ภาพใหญ่ประมาณ 3:2 (590×382) ภาพเล็กประมาณ 250×162 ย่อไม่เกิน ~300 KB ต่อรูป (เช่นที่ squoosh.app)

## ปุ่มที่ 4 บนเมนู (เช่น Resume / CV)
ใน `profile` ปลด comment บรรทัด `cv: { ... }` แล้วใส่ลิงก์ ถ้าไม่ใส่จะไม่แสดงปุ่ม

## รูปผลงาน
- รูปอยู่ในโฟลเดอร์ `images/` เป็นไฟล์ .webp (ย่อแล้ว โหลดเร็ว)
- ตั้งชื่อ: `<id>-cover.webp` = ปกการ์ด, `<id>-1.webp` = ภาพใหญ่ตอนเปิดหน้า, `<id>-2.webp`… = ภาพเล็กด้านขวา (กดแล้วสลับขึ้นเป็นภาพใหญ่)
- เพิ่มรูปใหม่: วางไฟล์ใน `images/` แล้วเพิ่มบรรทัดใน `media` ของผลงานนั้นใน `content.js`

## อัปเดตเว็บบน GitHub Pages
1. เข้า repo → ถ้าแก้ไฟล์เดียว: กดไฟล์นั้น → ไอคอนดินสอ → แก้ → **Commit changes**
2. ถ้าอัปโหลดไฟล์ทั้งชุดใหม่: **Add file → Upload files** ลากไฟล์ `index.html`, `style.css`, `app.js`, `content.js`, `README.md` และโฟลเดอร์ **`fonts`** และ **`images`** (ถ้ามีรูป) ไปวาง แล้ว Commit (ไฟล์ชื่อซ้ำจะถูกแทนที่)
3. ถ้าแก้ `style.css`/`app.js`/`content.js` ให้เปลี่ยนเลข `?v=9` ใน `index.html` เป็นเลขถัดไป เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่
4. รอ 1–2 นาที แล้วกด Ctrl+F5

> โฟลเดอร์ `fonts` ต้องอัปโหลดด้วย ไม่งั้นฟอนต์จะเพี้ยน
