# วิธีแก้เนื้อหาเว็บ Portfolio

แก้เนื้อหาทั้งหมดที่ไฟล์เดียว: **`content.js`** (เปิดด้วย Notepad / VS Code ได้)
ไฟล์อื่น (`index.html`, `style.css`, `app.js`) ไม่ต้องแตะ

## เพิ่มผลงาน
1. เปิด `content.js` หาส่วน `projects: [ ... ]`
2. copy บล็อกผลงาน 1 ชิ้น (ตั้งแต่ `{` ถึง `},`) แล้ววางต่อท้าย
3. แก้ `id` (ภาษาอังกฤษ ไม่มีเว้นวรรค เช่น `my-game`), ชื่อ, คำอธิบาย (ไทย + อังกฤษ)
4. ใส่รูปปกที่โฟลเดอร์ `images/` แล้วแก้ `cover: 'images/ชื่อไฟล์.jpg'`

## ลบ / ซ่อนผลงาน
- ลบ: ลบบล็อก `{ ... },` ของผลงานนั้นทิ้ง
- ซ่อนชั่วคราว: เพิ่มบรรทัด `hidden: true,` ในบล็อกนั้น

## เปลี่ยนสีเส้นนีออนบนการ์ด
ในแต่ละผลงานมี `accent: 'y'` (เหลือง) / `'g'` (เขียว) / `'r'` (แดง)

## ใส่วิดีโอ
ในส่วน `media: [ ... ]` ของผลงาน
- YouTube: `{ type: 'youtube', id: 'รหัสท้ายลิงก์' }`
- ไฟล์วิดีโอ: `{ type: 'video', src: 'images/clip.mp4' }` (ควรสั้นๆ และไฟล์เล็ก)

## ก่อนเผยแพร่ ต้องเปลี่ยน!
- ส่วน `contact` ที่ยังเป็น `your@email.com` / `your-name`
- ผลงานตัวอย่าง `project-02`, `project-03` (แก้หรือลบ)
- เช็คว่าข้อมูลของ Bar 410 ที่ใส่ไว้ เปิดเผยต่อสาธารณะได้

## ขึ้นออนไลน์ด้วย Netlify (ฟรี)
1. เข้า https://app.netlify.com/drop
2. ลาก **โฟลเดอร์ `portfolio` ทั้งโฟลเดอร์** ไปวาง
3. ได้ลิงก์ทันที (ตั้งชื่อ/ผูกโดเมนได้ใน Site settings)
4. แก้ไขทีหลัง: เข้าเว็บไซต์ใน Netlify → Deploys → ลากโฟลเดอร์ใหม่ทับ

## เคล็ดลับสำหรับหน้างานอีเวนต์
- ลิงก์ตรงไปผลงานชิ้นหนึ่ง: `https://โดเมน/#p-bar-410`
- บังคับภาษา: `https://โดเมน/?lang=en` หรือ `?lang=th` (ทำ QR แยกไทย/อังกฤษได้)
- ทำ PDF สำรอง: เปิดเว็บ → Ctrl+P (Print) → Save as PDF (มีสไตล์สำหรับพิมพ์ให้แล้ว)
- รูปควรย่อให้ไม่เกิน ~300 KB ต่อรูป (เช่นด้วย squoosh.app) เว็บจะเปิดเร็วบนเน็ตงาน
